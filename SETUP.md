## Что входит в комплект

- `README.md` — готовый профиль на русском языке.
- `assets/header.png` — шапка 1280 × 400.
- `assets/configscope.png`, `ritm.png`, `hrangor.png`, `arkanov.png` — сохранённые варианты графических карточек; в текущем README они не используются.
- SVG рядом с PNG — редактируемые исходники графики.
- `scripts/build_assets.py` — генератор PNG/SVG; нужен Python и Pillow. Запускать из любой папки: `python scripts/build_assets.py` с правильным путём к скрипту.

В текущем README используется только баннер `assets/header.png`. Проекты представлены текстовыми блоками и ссылками без внешних сервисов бейджей и статистики.
