# Владислав Бутвинский

**Ведущий разработчик 1С · Инструменты для разработчиков · Настольные приложения**

Разрабатываю корпоративные решения на **1С:Предприятие** и собственные приложения для автоматизации рабочих процессов. Отдельное направление — инструменты, которые связывают конфигурации 1С, Git и понятную историю изменений.

## Проекты

### ConfigScope

[![ConfigScope — история изменений 1С через объекты метаданных. C#, .NET 8, WPF, Git.](assets/configscope.png)](https://github.com/butvinskiyvsr-cmyk/onec-change-monitor)

Windows-приложение для просмотра изменений конфигураций 1С в Git: дерево объектов, история выбранного объекта и построчное сравнение BSL/XML. Поддерживает несколько локальных репозиториев и получение изменений с Git-серверов.

**Инженерная часть:** разделение на Domain, Application и Infrastructure; автоматические тесты; обновление с проверкой SHA-256 установщика.

[Репозиторий и документация →](https://github.com/butvinskiyvsr-cmyk/onec-change-monitor)

### RITM

[![RITM — задачи, проекты и планирование. Electron, JavaScript, Node.js, PostgreSQL.](assets/ritm.png)](https://github.com/butvinskiyvsr-cmyk/ritm-releases)

Приложение для задач, проектов и планирования: недельный и месячный планировщик, аналитика и диаграммы Ганта. Развиваю совместные проекты, роли, синхронизацию, создание задач из писем и интеграцию с Telegram.

**Инженерная часть:** локальное хранение, резервные копии, серверный API на Fastify/PostgreSQL и очередь синхронизации. Windows, Linux и браузерная версия проходят пользовательское тестирование.

Исходный код закрыт. [Публичные релизы →](https://github.com/butvinskiyvsr-cmyk/ritm-releases)

### HranGor

[![HranGor — история узлов метаданных и сверка выгрузки 1С. TypeScript, Electron, Git, XML.](assets/hrangor.png)](https://github.com/butvinskiyvsr-cmyk/hrangor-releases)

Инструмент для Windows, который строит дерево метаданных из Git/Gitea и показывает, кто, когда и что менял в каждом узле. Сверяет локальную XML-выгрузку с серверной историей и отделяет изменения формата от содержательных правок.

**Инженерная часть:** индексатор истории, смысловое сравнение XML, тесты ядра и автоматические обновления.

Исходный код закрыт. [Публичные релизы →](https://github.com/butvinskiyvsr-cmyk/hrangor-releases)

### Книга Арканов

[![Книга Арканов — персональная база знаний по 78 картам. Flutter, Dart, Windows.](assets/arkanov.png)](https://github.com/butvinskiyvsr-cmyk/kniga-arkanov-releases)

Настольный справочник по картам Таро: 78 карт, собственные тексты, сочетания, заметки, поиск и две темы оформления. Значения карт пользователь заполняет самостоятельно.

**Инженерная часть:** отделение пользовательских данных от описания колоды, автоматическое сохранение через временный файл и ежедневные резервные копии.

Исходный код закрыт. [Публичные релизы →](https://github.com/butvinskiyvsr-cmyk/kniga-arkanov-releases)
