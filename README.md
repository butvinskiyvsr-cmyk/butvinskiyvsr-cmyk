# Владислав Бутвинский

**Ведущий разработчик 1С · Продукты для работы и планирования · Инструменты для разработчиков**

Разрабатываю корпоративные решения на **1С:Предприятие** и собственные приложения для автоматизации рабочих процессов. Прохожу с продуктом путь от задачи и архитектуры до интерфейса, установки и обновлений. Отдельное направление — инструменты, которые помогают командам разбирать изменения конфигураций 1С через Git.

## Проекты

### 01 / RITM

**Задачи, проекты и планирование** · Windows · Linux · браузер

Недельный и месячный планировщик, аналитика, диаграммы Ганта и совместная работа. Развиваю синхронизацию между устройствами, создание задач из писем и интеграцию с Telegram.

**Инженерия:** локальное хранение и резервные копии, API на Fastify/PostgreSQL, очередь синхронизации. Приложение проходит пользовательское тестирование.

[Описание и установка →](https://github.com/butvinskiyvsr-cmyk/ritm-releases) · Исходный код закрыт

---

### 02 / HranGor

**История метаданных 1С через Git/Gitea** · Windows

Показывает, кто, когда и что менял в каждом узле конфигурации. Сверяет локальную XML-выгрузку с серверной историей и отделяет форматные изменения от содержательных.

**Инженерия:** индексатор истории, смысловое сравнение XML, тесты ядра и автоматические обновления.

[Описание и установка →](https://github.com/butvinskiyvsr-cmyk/hrangor-releases) · Исходный код закрыт

---

### 03 / ConfigScope

**Просмотр изменений конфигураций 1С в Git** · Windows · открытый код

Группирует изменения по объектам метаданных, показывает историю выбранного объекта и построчное сравнение BSL/XML. Работает с несколькими локальными репозиториями и Git-серверами.

**Инженерия:** слои Domain, Application и Infrastructure, автоматические тесты, обновления с проверкой SHA-256 установщика.

[Код, документация и релизы →](https://github.com/butvinskiyvsr-cmyk/onec-change-monitor)

---

### 04 / Книга Арканов

**Персональная база знаний по 78 картам Таро** · Windows

Собственные значения и сочетания карт, заметки, поиск и две темы оформления. Пользователь заполняет трактовки самостоятельно.

**Инженерия:** разделение пользовательских данных и описания колоды, сохранение через временный файл, ежедневные резервные копии.

[Описание и установка →](https://github.com/butvinskiyvsr-cmyk/kniga-arkanov-releases) · Исходный код закрыт
